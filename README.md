# 音乐可视化工具

基于傅立叶变换的音乐可视化工具，使用粒子系统将音频频谱信息转化为视觉效果。

## 功能特点

- 使用短时傅立叶变换（STFT）提取音频的时频信息
- 将频谱划分为低频、中频、高频三个频段
- 三层粒子系统：
  - **低频粒子**：大型脉冲效果（红-橙色）
  - **中频粒子**：圆形波纹效果（蓝-青色）
  - **高频粒子**：星尘闪烁效果（白-黄色）
- 实时音频播放与视觉效果同步
- 自动兼容不同采样率音频（运行时重采样到 22050Hz）
- MP3 读取失败时自动尝试转换为同名 WAV（依赖 ffmpeg）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
python main.py
```
运行后会弹出系统文件选择对话框，选择 `.mp3/.wav/.flac/.ogg` 音频文件即可开始可视化。

## 技术原理

### 音频处理
- 使用 soundfile 加载音频文件（MP3 失败时自动 ffmpeg 转 WAV 兜底）
- 应用短时傅立叶变换（STFT）提取频谱
- 将频谱划分为三个频段并计算能量

### 粒子系统
- 每个频段对应一个粒子发射器
- 粒子的数量、速度、大小由频段能量驱动
- 粒子具有生命周期，自动衰减和消失

### 可视化
- 使用 Pygame 进行实时渲染
- 音频播放与视觉效果同步
- 目标帧率：60 FPS

## 键盘控制

- `SPACE`: 暂停/继续
- `R`: 重播当前音频
- `ESC`: 退出
- `1/2/3`: 切换显示低/中/高频粒子
- `A`: 显示所有粒子
- `C`: 切换高对比动态模式（增强不同歌曲/桥段的视觉差异）
