# 前端设计指南 (FRONTEND_GUIDELINES)

## 概述
本文档定义音乐可视化工具的完整视觉设计系统，包括颜色、尺寸、动画、布局等所有视觉决策。

---

## 设计原则

### 核心原则
1. **沉浸感优先**：深色背景，鲜艳粒子，营造沉浸式体验
2. **性能优先**：简单的几何形状，避免复杂渲染
3. **层次清晰**：三层粒子系统，每层有独特的视觉特征
4. **流畅动感**：平滑的运动和渐变，避免突兀变化
5. **信息最小化**：减少 UI 元素，让用户专注于可视化效果

---

## 颜色系统

### 主色板

#### 背景色
- **深色背景**: `RGB(10, 10, 20)` / `#0A0A14`
  - 用途：主窗口背景
  - 原因：深色背景让粒子更突出，减少眼睛疲劳

#### 拖尾效果色
- **半透明黑色**: `RGBA(10, 10, 20, 40)`
  - 用途：每帧覆盖的半透明矩形
  - Alpha 值：40 (范围 0-255)
  - 效果：粒子轨迹逐渐淡化，产生拖尾

### 粒子色板

#### 低频粒子（Bass）
- **起始色**: `RGB(200, 50, 50)` / `#C83232`
  - 色相：红色
  - 饱和度：高
  - 亮度：中等
- **结束色**: `RGB(255, 150, 50)` / `#FF9632`
  - 色相：橙色
  - 饱和度：高
  - 亮度：高
- **渐变方式**：线性插值
- **插值公式**：
  ```python
  factor = normalized_energy  # 0.0 到 1.0
  r = 200 + int(55 * factor)
  g = 50 + int(100 * factor)
  b = 50
  color = (r, g, b)
  ```
- **视觉效果**：温暖、有力、冲击感

#### 中频粒子（Mids）
- **起始色**: `RGB(50, 100, 200)` / `#3264C8`
  - 色相：蓝色
  - 饱和度：高
  - 亮度：中等
- **结束色**: `RGB(50, 200, 200)` / `#32C8C8`
  - 色相：青色
  - 饱和度：高
  - 亮度：高
- **渐变方式**：线性插值
- **插值公式**：
  ```python
  factor = normalized_energy  # 0.0 到 1.0
  r = 50
  g = 100 + int(100 * factor)
  b = 200
  color = (r, g, b)
  ```
- **视觉效果**：冷静、流动、和谐

#### 高频粒子（Treble）
- **起始色**: `RGB(255, 255, 200)` / `#FFFFC8`
  - 色相：淡黄色
  - 饱和度：中等
  - 亮度：非常高
- **结束色**: `RGB(255, 255, 100)` / `#FFFF64`
  - 色相：黄色
  - 饱和度：高
  - 亮度：高
- **渐变方式**：线性插值
- **插值公式**：
  ```python
  factor = normalized_energy  # 0.0 到 1.0
  r = 255
  g = 255
  b = 200 - int(100 * factor)
  color = (r, g, b)
  ```
- **视觉效果**：明亮、闪烁、细腻

### 文本和 UI 色
- **主文本色**: `RGB(255, 255, 255)` / `#FFFFFF`
  - 用途：时间、FPS、模式显示
  - 透明度：255（完全不透明）
- **次要文本色**: `RGB(180, 180, 180)` / `#B4B4B4`
  - 用途：辅助信息
  - 透明度：200

### 颜色对比度
- **背景与低频粒子**：高对比度（红/橙 vs 深蓝黑）
- **背景与中频粒子**：高对比度（蓝/青 vs 深蓝黑）
- **背景与高频粒子**：极高对比度（黄/白 vs 深蓝黑）
- **粒子之间**：互补色系统（暖色 vs 冷色 vs 中性）

## 尺寸系统

### 窗口尺寸
- **宽度**: 1280 像素
- **高度**: 720 像素
- **纵横比**: 16:9
- **窗口模式**: 固定大小，不可调整
- **全屏**: 不支持（可选功能）

### 粒子尺寸

#### 低频粒子
- **最小尺寸**: 8 像素（直径）
- **最大尺寸**: 20 像素（直径）
- **计算公式**: `size = 8 + normalized_energy * 12`
- **尺寸变化**: 随生命周期线性缩小
  ```python
  decay_factor = lifetime / max_lifetime
  current_size = original_size * decay_factor
  ```

#### 中频粒子
- **最小尺寸**: 4 像素（直径）
- **最大尺寸**: 10 像素（直径）
- **计算公式**: `size = 4 + normalized_energy * 6`
- **尺寸变化**: 随生命周期线性缩小

#### 高频粒子
- **最小尺寸**: 2 像素（直径）
- **最大尺寸**: 5 像素（直径）
- **计算公式**: `size = 2 + normalized_energy * 3`
- **尺寸变化**: 随生命周期线性缩小

### 空间布局

#### 低频粒子发射点
- **位置**: 屏幕中心
- **坐标**: `(640, 360)`
- **固定**: 是

#### 中频粒子轨道中心
- **中心点 1**: 屏幕中心 `(640, 360)`
- **中心点 2**: 左上象限 `(320, 180)`
- **中心点 3**: 右上象限 `(960, 180)`
- **中心点 4**: 左下象限 `(320, 540)`
- **中心点 5**: 右下象限 `(960, 540)`
- **计算规则**:
  - 象限中心 = 屏幕尺寸的 1/4 和 3/4 位置
  - 左上: `(width/4, height/4)`
  - 右上: `(3*width/4, height/4)`
  - 左下: `(width/4, 3*height/4)`
  - 右下: `(3*width/4, 3*height/4)`

#### 中频粒子轨道半径
- **最小半径**: 50 像素
- **最大半径**: 200 像素
- **计算公式**: `radius = 50 + normalized_energy * 150`

#### 高频粒子初始位置
- **X 范围**: 0 到 1280 像素（随机）
- **Y 范围**: 0 到 720 像素（随机）
- **分布**: 均匀随机

### 文本和 UI 元素尺寸

#### 字体
- **字体家族**: Pygame 默认字体（或 Arial）
- **字体大小**:
  - 主要信息（时间）: 24 像素
  - 次要信息（FPS、模式）: 18 像素

#### 文本位置
- **播放时间**: 右上角，距离边缘 20 像素
  - 坐标: `(1260 - text_width, 20)`
- **FPS**: 左上角，距离边缘 20 像素
  - 坐标: `(20, 20)`
- **显示模式**: 左下角，距离边缘 20 像素
  - 坐标: `(20, 680)`

## 动画系统

### 粒子运动

#### 低频粒子运动
- **运动类型**: 线性径向运动
- **初始速度**: 2-8 像素/帧
- **速度公式**: `speed = 2 + normalized_energy * 6`
- **方向**: 随机角度（0-360 度）
- **加速度**: 无
- **每帧更新**:
  ```python
  x += vx
  y += vy
  ```

#### 中频粒子运动
- **运动类型**: 圆周运动
- **角速度**: 0.05-0.10 弧度/帧
- **角速度公式**: `angular_speed = 0.05 + normalized_energy * 0.05`
- **半径**: 动态（由能量决定）
- **每帧更新**:
  ```python
  angle += angular_speed
  x = center_x + radius * cos(angle)
  y = center_y + radius * sin(angle)
  ```

#### 高频粒子运动
- **运动类型**: 随机游走（布朗运动）
- **速度**: 0.5-3 像素/帧
- **速度公式**: `speed = 0.5 + normalized_energy * 2.5`
- **方向变化**: 每帧随机微调
- **每帧更新**:
  ```python
  angle += random.uniform(-0.3, 0.3)  # 随机角度变化
  vx = speed * cos(angle)
  vy = speed * sin(angle)
  x += vx
  y += vy
  ```

### 粒子生命周期动画

#### 透明度衰减
- **衰减类型**: 线性
- **初始 Alpha**: 255（完全不透明）
- **最终 Alpha**: 0（完全透明）
- **计算公式**:
  ```python
  decay_factor = lifetime / max_lifetime
  alpha = int(255 * decay_factor)
  ```

#### 尺寸衰减
- **衰减类型**: 线性
- **初始尺寸**: 由能量决定
- **最终尺寸**: 0
- **计算公式**:
  ```python
  decay_factor = lifetime / max_lifetime
  current_size = original_size * decay_factor
  ```

### 拖尾效果动画
- **实现方式**: 每帧绘制半透明矩形覆盖整个屏幕
- **矩形颜色**: `RGBA(10, 10, 20, 40)`
- **效果**: 旧粒子逐渐淡化，新粒子保持鲜艳
- **淡化速度**: 由 Alpha 值控制（40 表示较慢淡化）

### 帧率和时间
- **目标帧率**: 60 FPS
- **最低可接受帧率**: 30 FPS
- **帧率控制**: `pygame.time.Clock.tick(60)`
- **时间步长**: 固定（不使用 delta time）

### 粒子形状
- **形状**: 圆形（实心）
- **绘制方法**: `pygame.draw.circle()`
- **抗锯齿**: 否（性能考虑）
- **边框**: 无

- **覆盖范围**: 整个窗口 (0, 0, 1280, 720)

## 透明度和混合

### 粒子透明度
- **实现方式**: 使用 Pygame Surface 的 per-pixel alpha
- **创建方法**:
  ```python
  surface = pygame.Surface((diameter, diameter), pygame.SRCALPHA)
  pygame.draw.circle(surface, (r, g, b, alpha), (radius, radius), radius)
  screen.blit(surface, (x - radius, y - radius))
  ```

### 拖尾效果透明度
- **实现方式**: 使用半透明 Surface 覆盖
- **创建方法**:
  ```python
  trail_surface = pygame.Surface((1280, 720))
  trail_surface.set_alpha(40)
  trail_surface.fill((10, 10, 20))
  screen.blit(trail_surface, (0, 0))
  ```

### 混合模式
- **默认混合**: Alpha 混合（BLEND_ALPHA_SDL2）
- **特殊混合**: 无（不使用加法混合或其他特殊模式）

## 性能优化指南

### 渲染优化
1. **使用简单形状**: 圆形比多边形快
2. **避免过度绘制**: 限制粒子数量
3. **批量操作**: 尽可能减少 blit 调用
4. **避免实时计算**: 预计算颜色渐变表

### 内存优化
1. **对象池**: 重用粒子对象而不是频繁创建销毁
2. **Surface 缓存**: 缓存常用的 Surface
3. **及时清理**: 移除死亡粒子

### 视觉质量 vs 性能权衡
- **优先性能**: 如果帧率低于 30 FPS，减少粒子数量
- **可选降级**:
  - 禁用拖尾效果
  - 减少粒子生命周期
  - 降低发射频率

## 设计决策记录

### 为什么选择深色背景？
- 让粒子颜色更突出
- 减少眼睛疲劳（长时间观看）
- 营造沉浸式体验
- 符合音乐可视化的常见风格

### 为什么使用三种颜色系统？
- 红/橙（低频）：温暖、有力，符合低音的感觉
- 蓝/青（中频）：冷静、流动，符合旋律的感觉
- 黄/白（高频）：明亮、闪烁，符合高音的感觉
- 三种颜色互补，视觉层次清晰

### 为什么粒子大小不同？
- 低频粒子大：低音能量强，视觉冲击力大
- 中频粒子中：旋律丰富，需要平衡
- 高频粒子小：高音细腻，数量多但不抢眼

### 为什么使用拖尾效果？
- 增加动感和流畅性
- 显示粒子运动轨迹
- 避免画面过于跳跃
- 营造梦幻氛围

### 为什么不使用复杂的 UI？
- 保持界面简洁
- 让用户专注于可视化效果
- 减少开发复杂度
- 符合沉浸式体验的设计原则

## 视觉效果示例描述

### 安静段落（低能量）
- 少量小粒子
- 运动缓慢
- 颜色偏向起始色（深红、深蓝、淡黄）
- 拖尾效果明显，画面较空

### 高潮段落（高能量）
- 大量大粒子
- 运动快速
- 颜色偏向结束色（橙色、青色、黄色）
- 粒子密集，画面饱满

### 节奏变化
- 低频突变：中心爆发大量红/橙粒子
- 中频突变：轨道半径突然增大，蓝/青粒子扩散
- 高频突变：屏幕各处闪烁黄/白粒子

## 可访问性考虑

### 色盲友好
- 使用亮度对比而不仅仅是色相对比
- 低频（红/橙）vs 中频（蓝/青）有明显的亮度差异
- 高频（黄/白）亮度最高，易于区分

### 光敏性癫痫
- 避免快速闪烁（帧率稳定在 30-60 FPS）
- 避免大面积高对比度快速切换
- 拖尾效果平滑过渡

### 低视力用户
- 高对比度（深色背景 + 鲜艳粒子）
- 文本足够大（18-24 像素）
- 重要信息（时间、模式）位置固定
