# 产品需求文档 (PRD)

## 项目概述

### 项目名称
音乐可视化工具 (Music Visualizer)

### 项目版本
v1.0

### 项目目标
创建一个基于傅立叶变换的音乐可视化桌面应用程序，将音频信号的频谱信息转化为实时的粒子系统视觉效果。

### 目标用户
- **主要用户**：《信号与系统》课程的学生（作为课程设计项目）
- **次要用户**：对音乐可视化感兴趣的开发者和创意编程爱好者

### 使用场景
1. **课程作业展示**：在课程答辩时演示对傅立叶变换的理解和应用
2. **学习工具**：通过可视化理解不同音乐的频谱特征
3. **创意探索**：为不同类型的音乐生成独特的视觉效果
4. **作品集项目**：展示编程能力和创意实现

## 核心功能

### 功能 1：音频文件选择
**描述**：用户通过系统原生文件对话框选择音频文件

**功能细节**：
- 支持的音频格式：.mp3, .wav, .flac, .ogg
- 使用 tkinter 的文件对话框
- 文件类型过滤器显示支持的格式
- 用户可以取消选择（程序退出）

**优先级**：P0（必须）

---

### 功能 2：音频预处理
**描述**：加载音频文件并进行短时傅立叶变换（STFT），提取频谱信息

**功能细节**：
- 使用 librosa 加载音频文件
- 采样率：22050 Hz
- STFT 参数：
  - FFT 窗口大小：2048
  - 帧移：512
  - 窗函数：Hann 窗
- 提取幅度谱和相位谱（相位谱保留但不强制使用）
- 频段分离：
  - 低频：20-250 Hz
  - 中频：250-4000 Hz
  - 高频：4000-11025 Hz（上限为奈奎斯特频率，SAMPLE_RATE=22050 时最高可分析频率）
- 计算每个频段的能量
- 对能量值进行对数映射：`log10(energy + 1)`
- 将所有帧的频谱数据存储在内存中
- 显示加载进度（控制台输出）

**优先级**：P0（必须）

---

### 功能 3：实时可视化渲染
**描述**：根据音频频谱信息，使用三层粒子系统生成实时视觉效果

**功能细节**：

#### 3.1 窗口设置
- 窗口大小：1280x720 像素
- 窗口模式：固定大小窗口（非全屏）
- 背景颜色：深色（RGB: 10, 10, 20）
- 目标帧率：60 FPS

#### 3.2 粒子系统架构
**三层粒子系统**：
1. 低频粒子层（Bass）
2. 中频粒子层（Mids）
3. 高频粒子层（Treble）

**粒子总数上限**：3000 个

#### 3.3 低频粒子（Bass）
**视觉特征**：
- 形状：圆形
- 大小范围：8-20 像素
- 颜色：深红色 (200, 50, 50) 到橙色 (255, 150, 50) 渐变
- 生命周期：30-60 帧

**运动模式**：
- 发射位置：屏幕中心 (640, 360)
- 运动方向：径向向外爆发
- 初始角度：随机 (0-360 度)
- 速度范围：2-8 像素/帧
- 速度由能量决定：`speed = 2 + normalized_energy * 6`

**发射逻辑**：
- 发射数量：`num = int(normalized_energy * 100)`
- 数量上限：100 个/帧
- 能量为 0 时不发射

**消失方式**：
- Alpha 值随生命周期线性衰减
- 大小随生命周期线性缩小
- 生命周期结束时从列表移除

#### 3.4 中频粒子（Mids）
**视觉特征**：
- 形状：圆形
- 大小范围：4-10 像素
- 颜色：蓝色 (50, 100, 200) 到青色 (50, 200, 200) 渐变
- 生命周期：40-80 帧

**运动模式**：
- 轨道中心：5 个固定点
  1. 屏幕中心：(640, 360)
  2. 左上象限：(320, 180)
  3. 右上象限：(960, 180)
  4. 左下象限：(320, 540)
  5. 右下象限：(960, 540)
- 粒子发射时随机选择一个中心
- 初始角度：随机 (0-360 度)
- 轨道半径：`radius = 50 + normalized_energy * 150` (50-200 像素)
- 角速度：`angular_speed = 0.05 + normalized_energy * 0.05` (弧度/帧)
- 每帧更新位置：
  - `angle += angular_speed`
  - `x = center_x + radius * cos(angle)`
  - `y = center_y + radius * sin(angle)`

**发射逻辑**：
- 发射数量：`num = int(normalized_energy * 200)`
- 数量上限：200 个/帧
- 能量为 0 时不发射

**消失方式**：
- Alpha 值随生命周期线性衰减
- 大小随生命周期线性缩小
- 生命周期结束时从列表移除

#### 3.5 高频粒子（Treble）
**视觉特征**：
- 形状：圆形
- 大小范围：2-5 像素
- 颜色：白色 (255, 255, 200) 到黄色 (255, 255, 100) 渐变
- 生命周期：20-40 帧

**运动模式**：
- 初始位置：屏幕范围内随机
- 运动方式：随机游走（布朗运动）
- 每帧随机改变方向（小角度）
- 速度范围：0.5-3 像素/帧
- 速度由能量决定：`speed = 0.5 + normalized_energy * 2.5`

**边界处理**：
- 粒子超出屏幕范围 (x < 0 或 x > 1280 或 y < 0 或 y > 720) 时立即消失

**发射逻辑**：
- 发射数量：`num = int(normalized_energy * 300)`
- 数量上限：300 个/帧
- 能量为 0 时不发射

**消失方式**：
- Alpha 值随生命周期线性衰减
- 大小随生命周期线性缩小
- 生命周期结束或超出边界时从列表移除

#### 3.6 背景拖尾效果
- 每帧在整个屏幕上绘制半透明黑色矩形
- 矩形颜色：(10, 10, 20)
- 透明度：Alpha = 40
- 效果：粒子轨迹逐渐淡化，产生拖尾视觉

#### 3.7 能量归一化
**对数映射**（预处理阶段）：
- 对原始能量值取对数：`log_energy = log10(energy + 1)`

**局部归一化**（运行时）：
- 滑动窗口大小：2 秒（约 86 帧）
- 计算局部最大值：`local_max = max(energy[frame-43:frame+43])`
- 归一化：`normalized_energy = log_energy / local_max`
- 归一化值范围：[0, 1]

#### 3.8 音频同步
- 使用 `pygame.mixer.music` 播放音频
- 每帧获取播放时间：`current_time_ms = pygame.mixer.music.get_pos()`
- 计算当前频谱帧索引：`frame_index = int((current_time_ms / 1000.0) * 22050 / 512)`
- 读取对应帧的频段能量数据
- 根据能量数据发射和更新粒子

**优先级**：P0（必须）

### 功能 4：用户交互控制
**描述**：用户可以在可视化播放过程中进行交互控制

**功能细节**：

#### 4.1 基础控制
- **SPACE 键**：暂停/继续播放
  - 暂停时音频停止，粒子停止更新
  - 继续时从暂停位置恢复
- **ESC 键**：退出可视化，返回文件选择界面

#### 4.2 显示模式切换
- **1 键**：仅显示低频粒子
- **2 键**：仅显示中频粒子
- **3 键**：仅显示高频粒子
- **A 键**：显示所有粒子（默认模式）

#### 4.3 可选控制（时间允许）
- **左箭头**：快退 5 秒
- **右箭头**：快进 5 秒

#### 4.4 信息显示（可选）
- 当前播放时间 / 总时间
- 当前 FPS
- 当前显示模式

**优先级**：P0（基础控制和显示模式切换），P1（可选控制和信息显示）

---

### 功能 5：播放结束处理
**描述**：音频播放结束后的行为

**功能细节**：
- 音频播放完毕后，自动返回文件选择界面
- 用户可以选择新的音频文件继续使用

**优先级**：P1（重要）

## 风险与缓解

### 风险 1：性能不足
**描述**：粒子数量过多导致帧率下降
**缓解措施**：
- 设置粒子数量上限
- 优化粒子更新逻辑
- 降低目标帧率到 30 FPS

### 风险 2：音频同步不准确
**描述**：视觉效果和音频播放不同步
**缓解措施**：
- 使用 Pygame.mixer 的时间戳
- 定期校准
- 如果问题严重，切换到基于帧计数的同步

### 风险 3：内存占用过大
**描述**：长音频文件导致内存不足
**缓解措施**：
- 限制支持的音频长度（< 10 分钟）
- 显示警告信息
- 如果问题严重，切换到实时处理

### 风险 4：音频格式不支持
**描述**：某些音频格式加载失败
**缓解措施**：
- 在 README 中说明依赖（ffmpeg）
- 提供清晰的错误提示
- 优先测试 .wav 格式

### 风险 5：窗口切换不流畅
**描述**：tkinter 和 Pygame 窗口切换有闪烁
**缓解措施**：
- 优化窗口关闭和启动顺序
- 添加短暂延迟
- 如果问题严重，考虑使用 Pygame 实现简单的文件列表
